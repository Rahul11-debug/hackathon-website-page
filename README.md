# 🚀 NEXUS 2026 - Full Stack Tech Fest Website

Complete tech fest landing page with registration system.

```

│   └── ...
│
```

## 🎯 Features

### Frontend
- ✅ Dark cyberpunk design
- ✅ GSAP animations (scroll-triggered)
- ✅ Registration modal form
- ✅ Responsive design
- ✅ Custom cursor
- ✅ 5 sections: Hero, About, Events, Schedule, Footer

### Backend
- ✅ REST API with Express
- ✅ MongoDB database
- ✅ Registration endpoints
- ✅ Data validation
- ✅ Email uniqueness check
- ✅ Statistics endpoint

## 📋 Tech Stack

### Frontend
- React 18
- Vite 5
- GSAP 3.12 (animations)
- Tailwind CSS 3
- ScrollTrigger

### Backend
- Node.js
- Express 4
- MongoDB + Mongoose 8
- CORS
- Validator
